## ❌ Onvoltooide / Geplande Functionaliteiten

Zaken die gepland zijn, in ontwikkeling zijn of nog niet zijn geïmplementeerd.

Voorbeeld:
- [ ] [US1] Als admin wil ik verdiepingen beheren (CRUD) om een gebouw met meerdere verdiepingen te structureren.
- [ ] [US2] Als admin wil ik kamers beheren (CRUD) om een grondplan (bovenaanzicht) per verdieping aan te maken.
- [ ] [US3] Domotica controls beheren (CRUD) zodat deze beschikbaar zijn voor gebruikers.
- [ ] [US4] Globale scenes beheren (CRUD) zodat deze toegankelijk zijn voor alle gebruikers
- [ ] [US5] Tijdsloten koppelen aan scènes (CRUD) zodat deze periodiek actief worden
- [ ] [US6] Domotica controls zoeken, filteren, bekijken en aanpassen
- [ ] [US7] Scenes (CRUD) beheren om eenvoudig eigen voorkeuren in te stellen
- [ ] [US8] Scenes activeren en deactiveren om onmiddellijk een bepaalde situatie of sfeer te bekomen
- [ ] [US9] De interface in dark/light/system modus zetten (system volgt het dark/light schema van het systeem van de gebruiker)
- [ ] [US10] Een logging view met data die de wijzigingen aan controls bevat in verschillende views oa. een grafiek view en wat interessante data (meest geschakelde lampen, temperatuurverloop over de tijd)
